# Погода Казахстана

Веб-приложение с погодой по городам Казахстана на трёх языках: қазақша, русский, English.

**Что умеет:**
- **живое небо на весь экран:** цвет зависит от погоды и времени суток, а поверх плывут облака, идёт дождь или снег, ночью мерцают звёзды (анимацию можно поставить на паузу, она учитывает системную настройку «меньше движения»);
- погода сейчас: температура, как ощущается, ветер, влажность, восход и закат;
- плавный график температуры на сутки и прогноз на 7 дней;
- **карта «Казахстан сейчас»:** 17 областных центров, Астана, Алматы и Шымкент светятся цветом своей температуры; нажмёшь на город — карта приблизится и прорисует его настоящие границы;
- поиск любого населённого пункта Казахстана и погода по геолокации;
- **сделан под телефон и правую руку:** внизу панель с разделами и большой кнопкой города справа, под большим пальцем; город выбирается в выдвижной шторке снизу, поиск тоже внизу;
- стеклянные панели, запоминает город и язык.

**Технологии:** HTML, CSS, JavaScript без фреймворков и сборки. Погода и поиск городов — [Open-Meteo](https://open-meteo.com/) (бесплатно, без ключа). Границы городов — © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), скачаны один раз скриптом `tools/fetch_shapes.py`.

## Как запустить у себя

```bash
python -m http.server 5173
```

Потом открыть http://localhost:5173 в браузере.

# Kazakhstan Weather

A weather web app for Kazakhstan cities in Kazakh, Russian and English: current conditions, hourly and 7-day forecasts, a west-to-east strip of 19 cities, city search and geolocation. Plain HTML, CSS and JavaScript. Data by [Open-Meteo](https://open-meteo.com/) (CC BY 4.0).
